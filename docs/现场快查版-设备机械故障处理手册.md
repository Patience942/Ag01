# 非标自动化设备机械故障现场快查版

> **适用：** 调试、维修、售后和现场操作人员。  
> **原则：** 先安全隔离，再机械排查；未经确认不得强行运行。

## 1. 30秒安全确认

- [ ] 按下急停
- [ ] 关闭电源、气源、真空源
- [ ] 释放残压
- [ ] 升降轴/机械臂已支撑
- [ ] 确认不会被他人重新启动

## 2. 按现象快速定位

| 现象 | 第一检查点 | 第二检查点 | 常见处理 |
|---|---|---|---|
| 机构完全不动 | 电源、急停、气压 | 电磁阀、卡滞、限位 | 恢复能源、清除卡滞、检查阀和限位 |
| 动作很慢 | 气压、节流阀 | 负载、导轨润滑 | 调整气压/节流，清洁润滑 |
| 动作抖动 | 导轨、丝杆 | 气缸缓冲、偏载 | 检查平行度、润滑、缓冲和安装 |
| 有异响 | 是否缺润滑 | 轴承、滑块、链条 | 停机确认来源，润滑或更换 |
| 到位无信号 | 磁性/接近开关位置 | 感应距离、线缆 | 调整开关并检查输入信号 |
| 位置偏移 | 夹具和定位销 | 联轴器、丝杆间隙 | 紧固、换定位件、校准原点 |
| 夹不紧 | 气压、夹爪间隙 | 定位面、工件尺寸 | 清洁、调压、更换垫块或定位销 |
| 吸盘掉料 | 真空表、吸盘密封 | 管路、过滤器、工件表面 | 检漏、换吸盘、清洁过滤器 |
| 皮带跑偏 | 皮带轮平行度 | 张力、辊筒水平度 | 调对中、调张力、更换皮带 |
| 旋转不到位 | 分度销、机械限位 | 负载偏心、传感器 | 清洁校正、调整限位和负载 |
| 机构撞击 | 缓冲器 | 限位、速度、原点 | 降速、调缓冲、复核软硬限位 |
| 运行后发热 | 润滑、负载 | 同轴度、轴承 | 停机测温，减载、校正或换轴承 |

## 3. 机械模块速查

### 导轨/滑块

- **卡顿全行程**：检查平行度、安装面和负载。
- **局部卡顿**：检查划伤、异物和变形。
- **金属声**：检查滚珠、滚道和润滑。
- **处理**：断能量→清洁→润滑→低速测试→必要时更换滑块。

### 丝杆/联轴器

- **电机转、滑台不动**：检查联轴器、键和紧固螺钉。
- **反向间隙大**：检查螺母、支撑轴承和安装刚性。
- **发热或异响**：检查同轴度、润滑和侧向负载。

### 气缸

- **不动作**：查气源、电磁阀、气管和机构卡滞。
- **速度慢**：查节流阀、气压和负载。
- **到位不信号**：调磁性开关，检查输入点。
- **垂直气缸**：维修前必须防坠落。

### 夹具/定位

- **夹不紧**：查气压、夹爪磨损和工件尺寸。
- **定位偏**：查定位销、基准面、夹具螺钉。
- **夹伤产品**：检查夹爪接触面、夹紧行程和压力。

### 真空吸取

- **吸不起**：查吸盘、管路、过滤器和工件表面。
- **搬运掉料**：查真空保持、泄漏和吸盘数量。
- **真空建立慢**：查过滤器堵塞、管路过长和发生器喷嘴。

## 4. 现场处理顺序

1. 清除产品、碎屑和卡料。
2. 检查是否有明显断裂、松动、变形和漏气。
3. 检查润滑、张力、气压和真空。
4. 手动低速确认机械运动阻力。
5. 检查传感器安装和信号。
6. 单步、空载、低速、负载逐级恢复。

## 5. 禁止事项

- 禁止带压拆卸气缸、接头或真空管路。
- 禁止用手直接进入夹具、模具和机械臂工作区。
- 禁止通过拆除限位或屏蔽传感器强行生产。
- 禁止未确认原因就反复复位、强行点动。
- 禁止使用型号不明或承载能力不足的替代件。

## 7. 需要升级处理的情况

出现以下情况应立即停止设备并通知主管或专业维修人员：

- 机架、支撑、焊缝或关键承力件变形/开裂
- 垂直轴失控或存在坠落风险
- 安全门、急停、限位失效
- 轴承严重发热、冒烟或有明显烧蚀气味
- 高压、液压或储能部件损坏
- 故障重复发生且无法确认根因
