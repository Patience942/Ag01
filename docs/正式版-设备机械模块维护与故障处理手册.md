## 1. 目的与范围

本手册用于规范非标自动化设备机械模块的安全操作、日常点检、定期维护、故障诊断和维修验证，降低设备停机风险，保证设备运行精度和人员安全。

本手册覆盖：机架底座、直线导轨、丝杆、皮带链条、气缸、夹具定位、旋转分度、轴承联轴器、真空吸盘、机械限位和缓冲器等模块。

> **重要说明：** 本手册为通用机械维护文件。具体承载、速度、压力、扭矩、润滑剂、备件型号和安全距离必须以实际设备设计资料为准。

## 2. 术语与职责

### 2.1 常用术语

- **预防性维护**：在故障发生前，按照周期进行检查、清洁、润滑、校准和更换。
- **关键备件**：故障后会导致设备长时间停机或影响安全、精度的配件。
- **重复定位精度**：机构多次回到同一目标位置时的位置一致性。
- **残余能量**：设备断电后仍储存在气缸、弹簧、重力轴、真空或液压系统中的能量。

### 2.2 职责

| 角色 | 主要职责 |
|---|---|
| 操作人员 | 按要求操作，进行班前点检，报告异常 |
| 维修人员 | 故障隔离、诊断、维修和验证 |
| 工程师 | 结构、参数、图纸和改善方案确认 |
| 主管/设备负责人 | 维修授权、风险确认和记录归档 |

## 3. 安全要求

### 3.1 维修前

1. 停止自动运行并按下急停。
2. 关闭主电源、气源、真空源和液压源。
3. 释放管路和蓄能元件的残余压力。
4. 对垂直轴、升降机构、机械臂和弹簧机构进行机械锁定。
5. 设置维修标识，防止他人误启动。

### 3.2 维修中

- 不得拆除安全防护后进行自动运行测试。
- 不得将手伸入夹具、模具、传动件和机械臂危险区域。
- 使用合适的工具和量具，禁止敲击精密导轨、丝杆和传感器。
- 更换件必须确认规格、承载、行程、压力和安装方向。

### 3.3 维修后

- 恢复防护装置、安全门和限位。
- 进行手动、单步、空载、低速和负载测试。
- 确认无异常声、振动、发热、漏气和位置偏移。
- 填写维修记录并关闭相关风险。

## 4. 设备机械模块说明

### 4.1 机架与底座

**功能：** 承载设备并保持安装基准。  
**重点检查：** 水平度、地脚、焊缝、型材连接、加强筋和防护板。  
**典型故障：** 晃动、共振、位置漂移、门板变形。  
**处理：** 调平、紧固、增加支撑、重新校准基准。

### 4.2 直线导轨

**功能：** 提供低阻力直线导向。  
**重点检查：** 清洁、润滑、平行度、间隙和滑块声音。  
**典型故障：** 卡顿、异响、爬行、局部阻力增大。  
**处理：** 清洁润滑、校正安装基准、排除偏载，必要时更换滑块。

### 4.3 丝杆和滚珠丝杠

**功能：** 将旋转运动转换为精确直线运动。  
**重点检查：** 同轴度、润滑、反向间隙、联轴器和轴承。  
**典型故障：** 异响、发热、定位误差、滑台不动。  
**处理：** 校正同轴度、检查联轴器和支撑轴承、测量间隙并更换损坏件。

### 4.4 传动件

包括同步带、链条、皮带轮、链轮、减速机和联轴器。重点检查张力、对中、润滑、键连接、紧固状态和磨损。皮带跑偏通常与皮带轮平行度或张力不一致有关；链条抖动通常与链轮偏心、磨损或润滑不足有关。

### 4.5 气缸与夹具

重点检查气压、节流、气管接头、活塞杆侧向力、夹爪磨损、定位销和夹紧重复精度。气缸维修前必须释放残压，垂直气缸必须防坠落。

### 4.6 旋转、真空和限位模块

旋转模块重点检查分度销、减速机间隙、限位块和负载偏心；真空模块重点检查吸盘密封、管路、过滤器、发生器和真空保持；限位模块重点检查缓冲器、软硬限位、原点和机械挡块。

## 5. 点检与保养

### 5.1 日常点检表

| 检查项 | 判定标准 | 结果 |
|---|---|---|
| 异响和振动 | 无异常声、无异常振动 | □合格 □异常 |
| 导轨和丝杆 | 无明显污染，润滑正常 | □合格 □异常 |
| 皮带和链条 | 无裂纹、掉齿，张力适当 | □合格 □异常 |
| 气缸和管路 | 无漏气，动作平稳 | □合格 □异常 |
| 夹具和定位销 | 无松动、明显磨损或变形 | □合格 □异常 |
| 真空吸取 | 真空值稳定，无掉料 | □合格 □异常 |
| 防护和限位 | 完整有效，无旁路 | □合格 □异常 |

### 5.2 保养周期

| 周期 | 内容 |
|---|---|
| 每班/每日 | 清洁、目视检查、异常声检查、气压/真空检查 |
| 每周 | 紧固件、张力、管路、传感器安装和限位检查 |
| 每月 | 导轨丝杆润滑、轴承温升、夹具精度和真空过滤器检查 |
| 按运行小时 | 按供应商要求更换润滑脂、皮带、吸盘、密封件和易损件 |

## 6. 故障诊断与处理

### 6.1 诊断原则

按照“安全隔离→确认现象→机械检查→气动/真空检查→传感器检查→控制信号确认→维修验证”的顺序执行。优先排除卡料、松动、异物、缺润滑、偏载和安装偏差，再检查电气和程序。

### 6.2 故障对照表

| 故障现象 | 可能原因 | 处理措施 |
|---|---|---|
| 设备晃动 | 地脚松动、底座不平、刚性不足 | 调平、紧固、增加支撑 |
| 导轨卡顿 | 异物、润滑不足、平行度异常 | 清洁、润滑、校正或换滑块 |
| 丝杆发热 | 同轴度异常、侧向负载、润滑不足 | 校正、减载、润滑并复测 |
| 皮带打滑/跑偏 | 张力不足、轮系不平行 | 调张力、校正轮系 |
| 气缸不动作 | 气压、阀、管路、卡滞异常 | 检查气源、阀、管路和机构 |
| 夹具定位偏 | 定位销磨损、夹具松动、来料异常 | 更换定位件、紧固并复校 |
| 旋转不到位 | 分度销、限位、传感器或偏载异常 | 调整/更换并验证重复精度 |
| 吸盘掉料 | 吸盘老化、泄漏、工件不洁 | 检漏、更换、清洁并增加检测 |
| 机构撞击 | 缓冲失效、速度高、限位偏移 | 调缓冲、降速、复核限位 |

## 8. 附录：故障关闭标准

故障满足以下条件后方可关闭：

- 故障原因已确认或形成明确的临时控制措施。
- 故障件已修复或更换，安装和紧固状态正常。
- 手动、单步、空载和负载测试通过。
- 安全装置、限位和防护已恢复。
- 维修记录、备件记录和改善措施已完成。
