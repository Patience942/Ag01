## 1. 文档目的

本手册用于规范非标自动化设备机械模块在交付后的安全运行、日常维护和故障处理，确保设备运行稳定、故障可控、备件可追踪、以及交付后的设备可持续稳定生产。文档适用于设备使用方、维护团队、交付团队和售后支持团队。

本手册覆盖：
- 机架底座与安装结构
- 直线导轨和滑块
- 丝杆与滚珠丝杠
- 皮带、链条、齿轮与传动件
- 气缸与夹具定位机构
- 旋转分度机构与搬运模块
- 真空吸盘与抓取机构
- 机械限位、缓冲器和防护装置
- 轴承、联轴器、减速机及其他关键连接件

---

## 2. 安全要求

### 2.1 基本原则

1. 任何维护、故障排查前，必须停机并按下急停。
2. 断开主电源、气源、真空源、液压源。
3. 释放剩余压力与残余真空，必要时对升降轴、机械臂和重力机构进行机械支撑。
4. 禁止在设备自动运行状态下拆卸防护罩、清理卡料或调整夹具。
5. 维修完成后必须进行手动、单步、空载、低速和负载验证。
6. 任何牵涉安全门、急停、限位、缓冲器、机械挡块的调整，必须经负责人确认。

### 2.2 高危提醒

- 垂直机构和重力机构存在坠落风险。
- 高速旋转部件可能存在飞出或缠绕风险。
- 气动和真空系统断开后仍可能残留压力或吸力。
- 夹具和工件可能在解除夹紧后突然弹出或滑落。

## 3. 设备点检与保养计划

### 3.1 每班/每日检查

- 检查设备是否存在异常声、振动、漏气、漏油、温升过高等现象。
- 检查导轨、丝杆、皮带、链条、夹具、定位销、抓手和限位装置是否有松动、磨损或卡滞。
- 检查气压和真空是否正常，是否有明显波动。
- 检查防护罩、门、急停、限位器是否完好。
- 检查工装和输送区域是否有残留碎屑、铁屑、油污、堵料。

### 3.2 每周检查

- 地脚螺栓、机架连接件、导轨固定螺钉、夹具固定螺钉是否松动。
- 皮带张力、链条松紧度和齐套状态。
- 真空系统及过滤器是否清洁、密封是否良好。
- 机械限位、缓冲器与原点状态。
- 关键运动部件重复定位精度是否偏移。

### 3.3 每月/按运行小时检查

- 导轨、丝杆、轴承、联轴器的润滑及磨损状态。
- 夹爪、定位销、吸盘及关键易损件更换情况。
- 密封件、过滤器、接头和管路状态。
- 关键机构的温升、振动和回差情况。

## 4. 设备交付验收重点

| 模块 | 重点验收内容 | 检查方式 | 交付资料 |
|---|---|---|---|
| 机架底座 | 刚性、水平度、地脚紧固 | 水平仪、目视与手动检查 | 总装图、安装说明 |
| 导轨和滑块 | 平行度、卡滞、摩擦、润滑 | 低速手动运动、测量 | 导轨型号、润滑要求 |
| 丝杆和滚珠丝杠 | 反向间隙、定位精度、发热 | 反向间隙测量、回差测试 | 丝杆参数、校准记录 |
| 传动件 | 张力、对中、磨损、跳齿 | 目视+手动检查 | 张紧方法、寿命要求 |
| 气缸和夹具 | 推力、到位、夹紧力 | 空载与负载动作测试 | 气路图、定位校准记录 |
| 旋转分度 | 转角、重复定位、限位 | 分度试验证 | 分度参数、校准方法 |
| 真空吸取 | 真空值、吸力、掉料控制 | 真空测试、抓取验证 | 吸盘规格、过滤器型号 |
| 防护与限位 | 安全门、危险区域、防护有效性 | 全范围动作确认 | 安全评估、装置图纸 |

## 5. 故障处理标准流程

1. 记录故障现象：时间、工位、设备编号、产品型号、运行工序、异常状态。
2. 安全隔离：按下急停、断电、断气、断真空、释放残余压力。
3. 观察与初判：是否出现卡料、断裂、明显变形、漏气、漏油、发热、松动或撞击。
4. 机械优先排查：导轨、丝杆、传动件、夹具、定位销、限位、缓冲器、地脚螺栓。
5. 气动和真空检查：检查气压、节流阀、过滤器、管路和吸盘密封。
6. 传感器和安装检查：检查开关位置、线缆连接、固定螺钉、机械状态。
7. 维修处理：清理、润滑、紧固、校正、修复或更换故障件。
8. 验证运行：手动低速、单步、空载、低速、负载逐步验证。
9. 复盘和归档：整理故障报告、原因、处理方案和改进措施。

---

## 6. 常见故障处理

| 故障现象 | 主要原因 | 处理方法 |
|---|---|---|
| 设备晃动 | 地脚松动、底座不平、刚性不足 | 调平、紧固、加支撑/减振 |
| 导轨卡顿 | 缺润滑、异物、平行度偏差 | 清洁、加润滑、校正安装 |
| 丝杆异响 | 轴承损坏、润滑不足、同轴度偏差 | 检查轴承、校正同轴度、补扬润滑 |
| 皮带跑偏 | 轮系不平行、张力不均 | 调整对中和张力 |
| 链条抖动 | 链轮磨损、链条松弛 | 调整链条和更换磨损件 |
| 气缸不动作 | 气压不足、阀失效、卡滞 | 检查气源、阀岛和机构阻力 |
| 夹不紧 | 气压不足、夹爪磨损、定位偏移 | 调整气压、清洁、换垫块 |
| 吸盘掉料 | 真空不足、吸盘破损、工件表面脏污 | 检漏、更换吸盘、清洁工件 |
| 机构撞击 | 缓冲器失效、限位偏移、速度过高 | 调整缓冲与限位、降低速度 |

## 8. 维修记录管理

### 8.1 记录内容

| 字段 | 内容 |
|---|---|
| 日期 | 维修发生时间 |
| 设备编号 | 具体设备或工位 |
| 故障现象 | 设备表现、工位状态 |
| 处理过程 | 观察、排查、修复步骤 |
| 根因判断 | 现象对应的根本原因 |
| 更换件 | 配件名称、型号、数量 |
| 验证结果 | 手动、单步、空载、负载验证 |
| 维修人 | 负责人签名 |
| 改善建议 | 后续预防措施 |

### 8.2 故障关闭标准

设备故障满足以下条件后，方可关闭：
- 动作正常，无异响、振动、冲击或发热。
- 故障件已修复或更换，固定牢固。
- 安全门、限位、防护和缓冲均恢复正常。
- 试运行通过，且无重复故障出现。
- 维修记录归档并纳入设备管理。

## 10. 结语

机械模块是非标自动化设备稳定运行的核心。真实有效的维护，不只是发现故障后更换零件，而是建立标准化的预防维护体系、及时处置异常、持续记录和复盘。只有形成“安全、规范、可追溯”的维护方式，设备才能长期稳定、生产才能高效持续。
