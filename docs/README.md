- 现场快查版：`docs/现场快查版-设备机械故障处理手册.md`
- 正式版：`docs/正式版-设备机械模块维护与故障处理手册.md`

## 文档用途说明

- 企业交付版：适合交付给客户、项目负责人、设备管理团队使用，重点强调验收、保养和交付管理。
- 现场快查版：适合调试人员、维修人员、操作员现场快速定位问题，便于执行应急处理。
- 正式版：适合作为内部标准化文件、设备管理制度、维护体系文件使用，内容更规范完整。

## 建议使用顺序

1. 先使用现场快查版处理故障，快速判断问题。
2. 需要规范管理时使用企业交付版。
3. 需要形成正式设备管理资料时使用正式版。
